# Дизайн-спека: лендинг ibo

**Дата:** 2026-07-06
**Статус:** утверждён
**Контекст:** заказчик дизайна не предоставил — визуальные решения на нашей стороне. Продукт — AI-чат для агрономов (диагностика болезней растений по фото, советы). Бэкенд: AI Agro API (`http://167.233.203.129`), фронт: Next.js 16 + Tailwind 4 + motion.

## Требования заказчика

- Одностраничный лендинг с информацией про AI-чат
- Header: название **ibo** + кнопки «Войти» и «Регистрация»
- Акцент на зелёный (агро/экология)
- Анимация на агро-тему на главном экране

## Утверждённые решения

- **Стиль:** тёмный премиум (тёмно-зелёный фон, неоново-зелёные акценты)
- **Анимация hero:** растущие неон-ростки — инлайн SVG + motion/react (path animation)
- **Секции:** Hero → Возможности → Как это работает (+ header, footer)
- **Язык:** только русский, тексты через i18n-файлы (структура под будущие ky/en)

## 1. Дизайн-система

### Палитра

| Токен | Цвет | Назначение |
|---|---|---|
| `bg` | `#081410` | основной фон (почти чёрный с зелёным подтоном) |
| `bg-elevated` | `#0D1F17` | карточки, header |
| `accent` | `#4ADE80` | неон-зелёный: CTA, ростки, акценты |
| `accent-dim` | `#22C55E` | hover, вторичные акценты |
| `text` | `#F0FDF4` | заголовки |
| `text-muted` | `#86A896` | описания, вторичный текст |
| `border` | `#1E3A2C` | границы карточек |

Неоновое свечение: `box-shadow`/`drop-shadow` цветом `#4ADE80` на 20–40% прозрачности.

### Типографика

- **Заголовки:** Unbounded (Google Fonts, кириллица). Fallback-решение: Geist, если Unbounded покажется слишком смелым на живой странице.
- **Текст:** Geist Sans (уже в проекте).
- Hero-заголовок: ~64px desktop / 36px mobile.

### Логотип

«ibo» lowercase, жирный, с неон-зелёной точкой после названия (`ibo●`) как фирменный знак.


- «Начать бесплатно» → `/register`, «Войти» → `/login`. Страницы auth — следующий этап; в рамках лендинга сами роуты не создаются, кнопки ссылаются на будущие пути.
- «Как это работает ↓» — плавный скролл к секции.

## 3. Анимация

### Hero-ростки (инлайн SVG + motion/react)

SVG на всю ширину низа hero: 5–7 стилизованных стеблей разной высоты.

Фазы при загрузке:
1. Стебли «прорастают» снизу вверх: `pathLength` 0→1, stagger 0.15s, ~1.2s на стебель
2. Листья раскрываются: scale 0→1 от точки крепления к стеблю
3. Постоянная фаза: покачивание rotate ±1.5°, период 4–6s, разные фазы у стеблей («ветер»)

### Вторичные анимации

- Fade-up секций при скролле (`whileInView`, срабатывает один раз)
- Hover-свечение кнопок и карточек

### Ограничения

- `prefers-reduced-motion` → статичные ростки, без анимаций
- Только `transform`/`opacity`, без layout-анимаций
- Анимация не блокирует LCP: текст hero рендерится первым

## 4. Архитектура компонентов

```
app/
  page.tsx                     # лендинг (Server Component, собирает секции)
src/components/
  layout/
    header.tsx                 # sticky header ('use client' — скролл-эффект)
    footer.tsx                 # Server Component
  landing/
    hero.tsx                   # Server: текст + CTA
    growing-sprouts.tsx        # 'use client': SVG-анимация ростков
    features.tsx               # Server: карточки возможностей
    how-it-works.tsx           # Server: 3 шага
    section-reveal.tsx         # 'use client': обёртка fade-up при скролле
src/lib/
  motion-tokens.ts             # тайминги/spring-пресеты
src/i18n/ru.json               # все тексты лендинга
```

Принцип: `'use client'` только в компонентах с анимацией/интерактивом, остальное — Server Components.

## 5. Критерии приёмки

- `tsc --noEmit` и `next build` проходят чисто
- Lighthouse performance ≥ 90 (mobile)
- Корректное отображение на 360px / 768px / 1440px
- `prefers-reduced-motion` даёт статичную версию
- Кнопки header ведут на `/login` и `/register`

## Вне скоупа

- Страницы `/login`, `/register` и auth-флоу (следующий этап)
- Локализации ky/en (структура i18n готова, переводы позже)
- Секции «Демо-превью чата» и «FAQ» (отклонены на брейншторме)
