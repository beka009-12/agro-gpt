# ibo v3: редизайн лендинга и чат на реальном API

**Дата:** 2026-07-09
**Источник дизайна:** прототип заказчика «ibo Прототип v3» (claude.ai/design, файл `ibo Прототип v3.dc.html`)
**База:** ветка `feat/auth-pages`, коммит `2040d0e` (v2-состояние зафиксировано чекпоинтами)

## Контекст и решения

Прототип v3 полностью заменяет стиль v2 («полевой журнал») и добавляет
полноценный чат-интерфейс. Утверждено с заказчиком:

- **V2-рестайл** закоммичен как чекпоинт (`d814ce5..2040d0e`), v3 строится поверх.
- **Подход:** рестайл на месте — обновляем токены и существующие компоненты,
  сохраняем i18n, section-reveal и структуру репо.
- **Чат:** реальный API (`POST /chat/` + `POST /diagnosis/`), не мок из прототипа.
- **Auth остаётся:** «Начать чат» ведёт на `/chat`, `proxy.ts` редиректит
  неавторизованных на `/login`; страницы login/register перекрашиваются в v3.

## Чат `/chat` (реальный API)

### UI (`src/components/chat/`)

- **`chat-header.tsx`:** белая полоса — ссылка «← На главную» → `/`,
  вертикальный разделитель, аватар (круг `accent` с 🌱 40px),
  «АгроБот» + строка «онлайн» с зелёной точкой. Кнопка выхода (LogoutButton)
  переезжает в правый край хедера.
- **`message-list.tsx`:** скролл-лента, автопрокрутка вниз при новых
  сообщениях. Бабблы:
  - бот: аватар 32px + бабл `mint-soft`, скругление `16/16/16/4`;
  - пользователь: бабл `accent`, белый текст, скругление `16/16/4/16`,
    отступ слева 15%;
  - появление — fadeUp (motion/react, существующие motion-токены).
- **Пустое состояние:** 🌱 56px на `mint-soft` с CSS-покачиванием
  (`sproutSway`, ±2°, 4s, отключается при `prefers-reduced-motion`),
  «Чем помочь на поле сегодня?», подпись, 4 чипа-саджеста из `ru.json`.
  Клик по чипу отправляет его текст как обычное сообщение (ответ реальный).
- **`typing-indicator.tsx`:** бабл бота с тремя точками
  (поочерёдное мигание/подъём, stagger 0.15s).
- **`chat-input.tsx`:** круглая кнопка 📎 (файл-инпут `accept="image/*"`),
  текстовое поле pill «Спросите про урожай, болезни, удобрения…»
  (Enter — отправить), круглая зелёная кнопка ↑. Во время ожидания ответа
  отправка заблокирована.
- **Фото:** в баббле пользователя — миниатюра выбранного изображения
  (object URL) + имя файла.

### Данные и API

- Состояние сообщений — `useState` в клиентском компоненте чата
  (`{ id, role: "user" | "bot", text, imageUrl? }`).
- **Route handler `app/api/chat/message/route.ts`** (POST, FormData:
  `chatId?`, `text?`, `image?`):
  1. Берёт токен из httpOnly-куки; без токена — 401.
  2. Если `chatId` нет — создаёт чат через `POST /chat/` бэкенда.
  3. Шлёт `POST /diagnosis/` (multipart: `chat_id`, `user_text?`,
     `user_image?`) и возвращает клиенту `{ chatId, answer }`.
- **`api-server.ts` дорабатывается:** сейчас жёстко ставит
  `Content-Type: application/json` — нужна передача multipart
  (заголовок не ставится для FormData, boundary выставляет fetch).
- **Ошибки:** ApiError → в ленту падает системное сообщение бота из i18n
  (`chat.errors.*`), typing-индикатор гасится, инпут разблокируется.
- `app/chat/page.tsx` остаётся server component: читает юзера из куки,
  рендерит клиентскую оболочку чата.

## Auth-страницы

`auth-card.tsx`, формы login/register и ui-примитивы
(`button.tsx`, `input.tsx`, `select.tsx`) перекрашиваются токенами
автоматически + точечные правки: pill-кнопки, скругления 16px, Manrope,
светлые поверхности. OTP-флоу и API-роуты не меняются.

## Вне объёма

- Kyrgyz/English локализации (структура i18n уже готова).
- История чатов, список сессий, стриминг ответов.
- Геолокация в `POST /diagnosis/` (`latitude`/`longitude` не отправляем).
- Тёмная тема.

## Проверка

- `tsc --noEmit` и `next build` после каждой задачи.
- Ручной флоу: лендинг → «Начать чат» → редирект на `/login` → OTP →
  `/chat` → текстовый вопрос → реальный ответ → вопрос с фото → ответ;
  «← На главную» и logout работают; адаптив на ~375px без
  горизонтального скролла.
