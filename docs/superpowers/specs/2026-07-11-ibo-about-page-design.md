Уважать reduced motion: `motion-reduce:transform-none`.

## Ограничения и решения

- Никакого `'use client'` в новых компонентах /about — всё статично.
- Тексты только через ru.json (как во всём проекте), включая aria-label'ы новых ссылок.
- Хекс-цвета прототипа мапятся на существующие токены; новые токены не вводятся, кроме случая рамки hover (если нет подходящего — допускается arbitrary value).
- Фото HYDROWOOLKS нет — плейсхолдер, без внешних картинок.
- KY-локали нет — «RU / KY» остаётся информационным чипом, не переключателем.
